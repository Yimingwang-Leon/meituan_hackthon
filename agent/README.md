# 订单外呼模拟器

这是一个本地命令行版的数字人外呼模拟器，不接电话链路，只做两件事：

1. 从 `orders/` 目录读取订单 JSON 文件
2. 按顺序让 Agent 主动发起对话，并在终端中与用户进行聊天模拟
3. 当 Agent 判断当前订单会话应结束时，自动停止当前订单输入并归档

## 目录约定

- `orders/`: 待处理订单
- `sessions/`: 每次模拟结束后生成的会话归档
- `src/`: Python 代码
- `main.py`: 命令行入口
- `.env.example`: 环境变量模板

## 订单格式

```json
{
  "userName": "王先生",
  "orderId": "MT20260509001",
  "eta": "今天 19:30",
  "address": "上海市杨浦区某小区",
  "notes": "如用户不方便接收，询问新的可接收时间"
}
```

## 运行方式

1. 创建虚拟环境
2. 安装依赖
3. 复制 `.env.example` 为 `.env`
4. 填写 `OPENAI_API_KEY`
5. 启动

```bash
cd agent
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## 交互命令

- `/next`: 结束当前订单，进入下一单
- `/quit`: 结束程序

## 会话结束逻辑

- 每轮模型都会返回一句给用户的话
- 同时返回一个是否应结束当前订单会话的标志
- 一旦模型判定当前会话应结束，程序不会再接受该订单的继续输入，而是直接归档并切到下一单

## 当前范围

当前版本只解决本地订单读取和会话模拟，还没有：

- 真正的电话通讯
- 订单状态回写
- 结构化结果提取
- 后台管理页面
